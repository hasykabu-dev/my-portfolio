# Hasy's Portfolio

橋本さんの活動や趣味（マンガ制作、旅行、ランニングなど）を紹介するためのポートフォリオサイト。

## 🌐 公開URL
https://my-portfolio-pi-vert-74.vercel.app/

## 🚀 概要
自身の趣味や活動をまとめ、発信することを目的に作成したサイトです。
各セクションからそれぞれの詳細ページへアクセスできます。

## 🛠 使用技術（Tech Stack）

### フロントエンド
- **HTML5**: 静的サイトとしての基礎的な技術を使用。
- **CSS3**: divと関連付け、装飾をする。
- **JavaScript**: 世界地図やスライドショーの動的コンテンツを実装

### ホスティング / デプロイ
- **Vercel**: GitHubで公開
