## 💻 どのように作ったか（技術スタックとこだわり）

### 1. フロントエンド（デザイン・レイアウト）
* **HTML5 / CSS3**
    * **こだわりの整列（Flexbox / Grid）**: 要素のテキスト量にかかわらず、ボタンやカードの高さがピシッと横一直線に揃う美しいアライメントを意識しました。
    * **統一感のあるデザイン**: グレーの下地に白の角丸カード（親子関係を意識したborder-radiusの計算）をベースにし、手作りのオリジナリティを表現。
    * **インタラクティブ演出**: マンガギャラリーでは、横4枚並びの画像にカーソルを合わせるとフワッと拡大して浮き上がるホバーエフェクト（`transform: scale`）を実装。

### 2. バックエンド / 自動化（今後実装予定）
* **Python / JavaScript**
    * 旅行ページでの動的な地図ピン生成（JavaScript）や、ランニングデータの自動取得・可視化に挑戦していきます。
